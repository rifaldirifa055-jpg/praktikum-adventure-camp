Deskripsi Program
Program console menggunakan bahasa C untuk membantu proses penyewaan peralatan camping. Program menampilkan daftar peralatan dan harga sewa, menghitung subtotal dan diskon berdasarkan lama penyewaan, mencetak struk, serta menyimpan dan menampilkan riwayat hingga 10 transaksi selama program berjalan.
Daftar Harga
No.	Peralatan	Harga per Hari
1	Tenda Kapasitas 4 Orang	Rp50.000
2	Sleeping Bag	Rp15.000
3	Kompor Portable	Rp20.000
4	Matras Camping	Rp10.000
5	Lampu Camping	Rp12.000


Ketentuan Diskon
- 1–2 hari: 0%
- 3–4 hari: 10%
- 5 hari atau lebih: 15%
Fitur
1. Menu utama yang berulang sampai pengguna memilih keluar.
2. Menampilkan daftar peralatan dan harga.
3. Penyewaan satu jenis peralatan per transaksi.
4. Validasi input angka, pilihan peralatan, nama, jumlah unit, dan lama sewa.
5. Struk penyewaan dengan subtotal, diskon, dan total bayar.
6. Riwayat hingga 10 transaksi, jumlah transaksi, dan total pendapatan.
